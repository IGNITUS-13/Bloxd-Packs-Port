      01

      Map familiar names

      Recognized Java block/item textures are renamed to matching Bloxd filenames using the built-in mapping table. Matching is best-effort, not a perfect one-click conversion.

      02

      Inventory & UI

      Java GUI sprites do not map directly to Bloxd’s web UI. The generated CSS is a safe starter you can edit; exact inventory selectors need testing against Bloxd’s current interface.

      03

      Private by design

      The ZIP is processed in your browser. The app does not upload your pack to a server.
